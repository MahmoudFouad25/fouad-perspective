# مقياس المحاور ٢ — النسخة التجريبية للمشاركين

نسخة لمقابلات «فكّر بصوت عالي». المشارك بيجاوب المقياس كله، ويعلّم أي سؤال وقفه. **ما بيشوفش أي نتيجة.**
والإجابات بتتسجل في Firestore في مجموعة منفصلة عن الإنتاج: `maqyas_axes_v2_pilot`.

| | الرابط |
|---|---|
| المشارك | https://mahmoudfouad25.github.io/fouad-perspective/three-axes/v2/pilot/ |
| المشارك بدفعة | https://mahmoudfouad25.github.io/fouad-perspective/three-axes/v2/pilot/?c=batch1 |
| الأدمن | https://mahmoudfouad25.github.io/fouad-perspective/three-axes/v2/pilot/admin.html |

```
pilot/
├── index.html · app.js · style.css   ← صفحة المشارك
├── admin.html                        ← صفحة الأدمن (جدول + تنزيل JSON + نسخ)
├── config.js                         ← مفاتيح فايربيز + اسم المجموعة + إيميلات الأدمن
├── items.json                        ← الأسئلة كلها. بيتولّد، ما يتعدّلش بإيد
├── build_items.py                    ← بيولّد items.json (وملف الفحص) من الدوك
└── firestore.rules                   ← المقطع اللي بيتلصق في قواعد المشروع
```

## لو الدوك اتعدّل

1. اقرا الدوك «مقياس المحاور ٢ — الأسئلة» كـ JSON (`documents.get`) واحفظه في ملف.
2. `python3 build_items.py doc.json` ← بيكتب `pilot/items.json` و`checks/items.json`، وبيرفض لو التاب الأساسي وتاب العميل مش متطابقين، أو لو كلام داخلي (اسم محور، «داخلي»، «استبدال») دخل ملف المشاركين.
3. `python3 ../checks/check_items.py` ← الفحص.
4. ارفع. كل مشارك بيتسجّل معاه هاش نسخة الأسئلة اللي جاوب عليها (`qVersion.hash`).

## نشر القواعد (مرة واحدة)

**١. Authentication ← Sign-in method:** اتأكد إن **Anonymous** و**Email/Password** متفعّلين (هما متفعّلين من أيام الميزان). وحساب الأدمن هو نفس حساب الميزان: `admin@fouad-academy.com`.

**٢. Firestore Database ← تبويب Rules.** ما تمسحش أي حاجة موجودة.

- انزل لآخر الملف لحد القاعدة العامة اللي شكلها: `match /{collection}/{doc=**} {`
- **فوقها مباشرة** الصق المقطع (١) من `firestore.rules`: الدالة `isAxpAdmin` ومقطع `match /maqyas_axes_v2_pilot/{uid}`.
- **جوّه القاعدة العامة** زوّد المجموعة على الاستثناءات. السطر اللي بيبدأ بـ `allow read, write: if (collection == 'sessions' ...` يبقى فيه كمان `|| collection == 'maqyas_axes_v2_pilot'` جوّه نفس القوس. من غير الخطوة دي، القاعدة العامة هتفتح المجموعة لأي حد.
- دوس **Publish**.

**٣. اتأكد:** افتح صفحة الأدمن وادخل. لو ظهر جدول (حتى لو فاضي) يبقى القواعد شغالة. لو ظهرت «قواعد الأمان رافضة القراءة» يبقى المقطع ما اتلصقش صح أو الإيميل مختلف.

## الحفظ

- على الجهاز بعد كل ضغطة. ولو المشارك قفل ورجع من نفس الجهاز، بيكمّل من نفس المكان.
- في فايربيز: أول ما يكتب اسمه، وبعد كل محطة، وفي الآخر. ولو الجهاز اتمسح والدخول المجهول لسه موجود، بيكمّل من فايربيز من أول محطة ما خلصتش.
- لو النت وقع: بيكمّل عادي، والإجابات بتتبعت أول ما يرجع.
- بعد ما المشارك يخلّص، وثيقته بتتقفل. ومحدش يقدر يمسح من الصفحات. المسح من Firebase Console بس.

## اللي في كل وثيقة

`name` · `age` · `cohort` (من `?c=`، والافتراضي «بدون») · `device` · `qVersion` · `status` (شغال / خلص) · `screen` (وصل لفين) · `startedAt` / `finishedAt` / `updatedAt` ·
`period` (`selected`, `impact`) ·
`st["1".."7"]` ← `startedAt`, `endedAt`, `answers`, و`order` (ترتيب الاختيارات اللي ظهر، في المحطتين ١ و٢) ·
الإجابة: في المحطتين ١ و٢ `{closest, farthest, none}`، وفي المحطات ٣ لـ٧ `{v: 0..4, label}`، وفي أسئلة الطرفين `{v: 1..5}` (١ = أقرب لـ«أ»)، ومع كل إجابة `t` (مللي ثانية من ظهور الشاشة لحد آخر ضغطة) و`changes` (عدد الضغطات) ·
`adaptive` (صيغة الاستبدال اللي ظهرت وحسابها) · `flags` (`{reasons, note}` لكل عبارة متعلّم عليها) · `closing` (`q1`, `q2`).

المحاور في الملفات مرموزة: `H` = الحفظ، `V` = الحيوية، `A` = الانتماء. وأرقام العبارات نفس أرقام الدوك (`s3n7` = المحطة ٣، العبارة ٧).

## قاعدة الاستبدال المؤقتة

⚑ مؤقتة لحد ما المحرك يتبني (مكتوبة في `app.js → computeAdaptive`):
نقط المحطة ١ (الأقرب +١، الأبعد −١، من غير المواقف الخفيفة). لو الفرق بين الأول والتاني ≤ ١ ← الصيغة العامة.
غير كده: الرئيسي = الأول، والمكبوت = اللي (إشارات السكوت في المحطة ٢ ناقص نقطه في المحطة ١) عنده أعلى. ولو الاتنين متعادلين ← الصيغة العامة.
