# تطبيق منظور الفؤاد

تطبيق مستقل في فولدر `app`، لا يعدّل أي ملف خارجه.

## الرابط
https://mahmoudfouad25.github.io/fouad-perspective/app/

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | شاشة الدخول (بنفس منطق `login.html`، ومعها الدخول التلقائي من رابط تليجرام `?uid=&token=`) |
| `home.html` | الشاشة الرئيسية: رحلاتي · المحفظة والكوبونات · حسابي |
| `core.js` | الاتصال بـ Firebase وحفظ الجلسة بنفس مفاتيح الموقع، حتى تفتح صفحات الكورسات مباشرة |
| `app.css` | التصميم |
| `manifest.webmanifest` | بيانات التثبيت: الاسم، الأيقونة، الألوان |
| `sw.js` | يحفظ واجهة التطبيق على الجهاز ويعرض صفحة «لا يوجد اتصال» |
| `offline.html` | صفحة عدم الاتصال |
| `icons/` | الأيقونات (مؤقتة — تُستبدل بشعارك بنفس الأسماء والمقاسات) |

## عند تعديل أي ملف في هذا الفولدر
غيّر رقم الإصدار في أول `sw.js` (مثلًا `fp-app-v1` ← `fp-app-v2`) حتى يأخذ الطلاب النسخة الجديدة.

## الأيقونات المطلوبة لو استبدلتها
- `icon-192.png` و `icon-512.png`: الشعار بحواف مستديرة.
- `maskable-512.png`: الشعار في المنتصف بمساحة ٧٠٪ فقط، والخلفية تملأ المربع كله (أندرويد يقصّ الأطراف).
- `apple-touch-icon.png`: ١٨٠×١٨٠، مربع بلا حواف مستديرة (آيفون يستدير الحواف بنفسه).
